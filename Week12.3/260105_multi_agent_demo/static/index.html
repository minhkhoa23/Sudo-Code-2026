Kiến trúc và cách demo
Context → Supervisor → Researcher / Operations → Supervisor → Final. Mọi tác vụ ghi/gửi rẽ qua LangGraph interrupt → người dùng duyệt → executor. Checkpoint và memory lưu ở SQLite, giữ qua restart.
Thử hỏi giờ Chủ nhật; hỏi tiếp “Còn thứ Bảy?”. Chọn lưu memory rồi từ chối, sau đó thử lại và duyệt. Tạo thread mới để đọc memory. Cuối cùng thử “Tra cứu + tạo ticket” và xem cả hai specialist trong trace.
Gemini mode sẽ hỏi duyệt từng request model, rồi hỏi duyệt riêng cho tool ghi. Outbox chỉ là bản nháp local. /docs có API tương tác. Demo session token lưu trên trình duyệt; không chia sẻ token.
